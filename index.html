    Sem chave o app já funciona. Uma chave gratuita acelera a busca (de 3 para 10 consultas/s). Gere em conta NCBI → API Key. Fica salva apenas neste navegador.

    Fonte: PubMed via NCBI E-utilities. Cada periódico é consultado por sua abreviação NLM (campo [ta]); os artigos (os mais recentes que entraram no PubMed na janela escolhida) são ordenados por data e classificados em dois níveis a partir do título, dos descritores MeSH, das palavras-chave dos autores e do resumo: subespecialidade (1º nível) e grupo de doenças (2º nível). Selecione uma subespecialidade para navegar pelos grupos de doenças; um mesmo artigo pode receber 2–3 rótulos quando o tema é transversal (ex.: RBD em sono e movimento; encefalite autoimune em epilepsia, cognição e neuroimunologia).
    Aplicativo estático: todo o processamento ocorre no navegador. Para hospedar, basta publicar este index.html no GitHub Pages. A classificação por subespecialidade é heurística e serve para triagem rápida, não substitui a leitura do artigo.
    Instalar no celular: Android/Chrome mostra o botão Instalar app acima. No iPhone, abra no Safari e use Compartilhar → Adicionar à Tela de Início.
